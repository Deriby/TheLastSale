# Projeto Godot — 0.36.0

**[Baixar TheLastSale_Godot_0.36.0.zip](https://github.com/Deriby/TheLastSale/raw/refs/heads/main/downloads/project/TheLastSale_Godot_0.36.0.zip)**

Extraia em uma pasta nova, importe `project.godot` no **Godot 4.4.1**, aguarde a importação e pressione **F5**. O pacote contém código, modelos animados, cenário, sons, texturas, vídeo e ferramentas. Blender não é necessário para jogar.

A revisão da campanha corrige configurações que não ficavam salvas ao sair com Esc, a informação de prova na fuga e a oscilação da corrida quando o fôlego esgota. A campanha é conferida desde uma partida nova até o epílogo, com retomadas e interações físicas. Modelos, animações, rodinha, circuitos e interfaces do computador permanecem. [Prévia real](../../docs/review_v036/revisao_preview.mp4) · [Escopo e validação](../../docs/review_v036/README.md) · [Instruções completas](../../tools/project_archive_readme.md).

O ZIP é o projeto para o editor, sem EXE. Caches `.godot`, saves e Git ficam fora do pacote. `PROJETO_MANIFESTO.json` lista hashes dos arquivos; o `.sha256` ao lado verifica o ZIP. [Verificação da distribuição](release_verification.json).
