# Projeto Godot — 0.23.1

**[Baixar TheLastSale_Godot_0.23.1.zip](https://github.com/Deriby/TheLastSale/raw/refs/heads/main/downloads/project/TheLastSale_Godot_0.23.1.zip)**

Extraia em uma pasta nova, importe `project.godot` no **Godot 4.4.1**, aguarde a importação e pressione **F5**. O pacote contém código, modelos animados, cenário, sons, texturas, vídeo e ferramentas. Blender não é necessário para jogar.

A campanha agora tem a primeira versão jogável de sexta, sábado e domingo, com investigação, perseguição cooperativa, coberturas e três epílogos. A 0.23.1 corrige o piso que deslizava ao mover a câmera nos modos PS1 e PS1/2. As texturas repetidas ficam presas ao cenário e a deformação afim de texturas UV tem limites suaves; as seleções Desligada/Suave/Marcada continuam independentes. HUD, física e circuitos de energia são preservados, assim como os modelos e animações da 0.22.0. [Comparações e validação](../../docs/psx_v0231/README.md). [Instruções completas do pacote](../../tools/project_archive_readme.md).

O ZIP é o projeto para o editor; não é um executável de Windows. Caches `.godot`, saves e Git ficam fora do pacote. `PROJETO_MANIFESTO.json` lista hashes dos arquivos; o `.sha256` ao lado verifica o ZIP. [Verificação da distribuição](release_verification.json).
