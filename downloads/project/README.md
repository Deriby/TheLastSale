# Projeto Godot — 0.33.0

**[Baixar TheLastSale_Godot_0.33.0.zip](https://github.com/Deriby/TheLastSale/raw/refs/heads/main/downloads/project/TheLastSale_Godot_0.33.0.zip)**

Extraia em uma pasta nova, importe `project.godot` no **Godot 4.4.1**, aguarde a importação e pressione **F5**. O pacote contém código, modelos animados, cenário, sons, texturas, vídeo e ferramentas. Blender não é necessário para jogar.

A 0.33.0 trabalha o clímax de domingo: investigação mais quieta, última cabeça opcional entre as caixas, passos posicionais do perseguidor, busca pelo último ponto conhecido e um respiro antes do epílogo. As decisões de sábado, três finais, energia, modelos, animações, saves e câmera pela rodinha ficam preservados. [Prévia real com áudio](../../docs/climax_v033/domingo_preview.mp4) · [Detalhes e validação](../../docs/climax_v033/README.md) · [Instruções completas](../../tools/project_archive_readme.md).

O ZIP é o projeto para o editor; não é um executável de Windows. Caches `.godot`, saves e Git ficam fora do pacote. `PROJETO_MANIFESTO.json` lista hashes dos arquivos; o `.sha256` ao lado verifica o ZIP. [Verificação da distribuição](release_verification.json).
