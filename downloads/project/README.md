# Projeto Godot — 0.31.0

**[Baixar TheLastSale_Godot_0.31.0.zip](https://github.com/Deriby/TheLastSale/raw/refs/heads/main/downloads/project/TheLastSale_Godot_0.31.0.zip)**

Extraia em uma pasta nova, importe `project.godot` no **Godot 4.4.1**, aguarde a importação e pressione **F5**. O pacote contém código, modelos animados, cenário, sons, texturas, vídeo e ferramentas. Blender não é necessário para jogar.

A 0.31.0 acrescenta oportunidades silenciosas de ver só a cabeça do assassino atrás de cantos e gôndolas, na sexta e no sábado. Muitas podem passar sem ser percebidas; o jogo não gera nota ou fala para confirmar essas aparições. A versão conserva modelos, animações, energia, controles, saves e câmera pela rodinha. [Exemplos em tempo normal e validação](../../docs/watching_v031/README.md). [Instruções completas](../../tools/project_archive_readme.md).

O ZIP é o projeto para o editor; não é um executável de Windows. Caches `.godot`, saves e Git ficam fora do pacote. `PROJETO_MANIFESTO.json` lista hashes dos arquivos; o `.sha256` ao lado verifica o ZIP. [Verificação da distribuição](release_verification.json).
