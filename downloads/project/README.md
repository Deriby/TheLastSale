# Projeto Godot — 0.38.0 / Godot 4.7

**[Baixar TheLastSale_Godot_0.38.0.zip](https://github.com/Deriby/TheLastSale/raw/refs/heads/main/downloads/project/TheLastSale_Godot_0.38.0.zip)**

Extraia em uma pasta nova, importe `project.godot` no **Godot 4.7**, aguarde a importação e pressione **F5**. O pacote contém código, modelos animados, cenário, sons, texturas, vídeo e ferramentas. Blender não é necessário para jogar.

A 0.38.0 revisa a encenação dos sustos, a peça do Bryan nos fundos, focos breves e eventos por proximidade. [Prévia com áudio](../../docs/horror_v038/sustos_preview.mp4) · [Detalhes](../../docs/horror_v038/README.md).

Uncanny Valley toca na intro e no menu, com continuidade ao pular a abertura, repetição e saída suave ao começar ou continuar. O MP3 recebido está incluído sem recodificação. Música / rádio controla a faixa, separado dos efeitos. O projeto recebe os metadados de importação do Godot 4.7 e mantém os dados originais dos modelos, animações e mecânicas. [Prévia real com a música](../../docs/music_v037/uncanny_valley_preview.mp4) · [Validação](../../docs/music_v037/README.md).

As sete capturas antigas da sexta 0.18 permanecem [na galeria do GitHub](https://github.com/Deriby/TheLastSale/tree/main/docs/friday_v018); o espaço no ZIP é usado pela faixa completa. O ZIP é o projeto para o editor, sem EXE. Caches, saves e Git ficam fora do pacote. `PROJETO_MANIFESTO.json` lista hashes dos arquivos; o `.sha256` verifica o ZIP.
