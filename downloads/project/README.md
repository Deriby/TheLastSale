# Projeto Godot — 0.30.2

**[Baixar TheLastSale_Godot_0.30.2.zip](https://github.com/Deriby/TheLastSale/raw/refs/heads/main/downloads/project/TheLastSale_Godot_0.30.2.zip)**

Extraia em uma pasta nova, importe `project.godot` no **Godot 4.4.1**, aguarde a importação e pressione **F5**. O pacote contém código, modelos animados, cenário, sons, texturas, vídeo e ferramentas. Blender não é necessário para jogar.

A 0.30.2 troca a travessia ostensiva pelo salão por um vulto parcialmente encoberto no batente do estoque, usando o assassino original. A cena aguarda uma olhada periférica sem outras testemunhas; não pisca luzes, bate portas ou força conversa. Modelos, animações, energia, controles e câmera pela rodinha foram preservados. [Prévia em tempo normal e validação](../../docs/subtle_v0302/README.md). [Instruções completas](../../tools/project_archive_readme.md).

O ZIP é o projeto para o editor; não é um executável de Windows. Caches `.godot`, saves e Git ficam fora do pacote. `PROJETO_MANIFESTO.json` lista hashes dos arquivos; o `.sha256` ao lado verifica o ZIP. [Verificação da distribuição](release_verification.json).
