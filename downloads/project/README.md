# Projeto Godot — 0.40.0 / Godot 4.7

**[Baixar TheLastSale_Godot_0.40.0.zip](https://github.com/Deriby/TheLastSale/raw/refs/heads/main/downloads/project/TheLastSale_Godot_0.40.0.zip)**

Extraia em uma pasta nova, importe `project.godot` no **Godot 4.7**, aguarde a importação e pressione **F5**. O pacote contém código, modelos animados, cenário, sons, texturas, vídeo e ferramentas. Blender não é necessário para jogar.

A 0.40.0 melhora luz, cores e acabamento do cenário: balcão quente, rua fria, neon contido e paredes com sinais de uso. [Prévia real](../../docs/visual_v040/direcao_visual_preview.mp4) · [Antes/depois e detalhes](../../docs/visual_v040/README.md). As interfaces da 0.39.0, os sustos e a campanha permanecem.

Uncanny Valley toca na intro e no menu, com continuidade ao pular a abertura, repetição e saída suave ao começar ou continuar. O MP3 recebido está incluído sem recodificação. Música / rádio controla a faixa, separado dos efeitos. O projeto recebe os metadados de importação do Godot 4.7 e mantém os dados originais dos modelos, animações e mecânicas. [Prévia real com a música](../../docs/music_v037/uncanny_valley_preview.mp4) · [Validação](../../docs/music_v037/README.md).

As sete capturas antigas da sexta 0.18 permanecem [na galeria do GitHub](https://github.com/Deriby/TheLastSale/tree/main/docs/friday_v018); o espaço no ZIP é usado pela faixa completa. O ZIP é o projeto para o editor, sem EXE. Caches, saves e Git ficam fora do pacote. `PROJETO_MANIFESTO.json` lista hashes dos arquivos; o `.sha256` verifica o ZIP. [Verificação da distribuição](release_verification.json).
