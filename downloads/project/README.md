# Projeto Godot — 0.26.0

**[Baixar TheLastSale_Godot_0.26.0.zip](https://github.com/Deriby/TheLastSale/raw/refs/heads/main/downloads/project/TheLastSale_Godot_0.26.0.zip)**

Extraia em uma pasta nova, importe `project.godot` no **Godot 4.4.1**, aguarde a importação e pressione **F5**. O pacote contém código, modelos animados, cenário, sons, texturas, vídeo e ferramentas. Blender não é necessário para jogar.

A 0.26.0 refaz a base das animações com referências de Quaternius (CC0), retargeting para os 11 rigs, contato de cada passada e correção do pivô das mangas dos clientes. Preserva os modelos, texturas, pesos, mecânicas, física, circuitos de energia, HUD, intro Two Brothers Lab e menu de suspense. [Vídeo e validação](../../docs/motion_v026/README.md). [Instruções completas](../../tools/project_archive_readme.md).

O ZIP é o projeto para o editor; não é um executável de Windows. Caches `.godot`, saves e Git ficam fora do pacote. `PROJETO_MANIFESTO.json` lista hashes dos arquivos; o `.sha256` ao lado verifica o ZIP. [Verificação da distribuição](release_verification.json).
