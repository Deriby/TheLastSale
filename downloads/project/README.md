# Projeto Godot — 0.32.0

**[Baixar TheLastSale_Godot_0.32.0.zip](https://github.com/Deriby/TheLastSale/raw/refs/heads/main/downloads/project/TheLastSale_Godot_0.32.0.zip)**

Extraia em uma pasta nova, importe `project.godot` no **Godot 4.4.1**, aguarde a importação e pressione **F5**. O pacote contém código, modelos animados, cenário, sons, texturas, vídeo e ferramentas. Blender não é necessário para jogar.

A 0.32.0 acrescenta vestígios discretos, uma caixa que muda fora da vista, sons nos fundos e um encontro raro com o assassino dentro do carro já estacionado. Não há aviso automático confirmando esses novos momentos. A versão conserva modelos, animações, energia, controles, saves e câmera pela rodinha. [Prévia real com áudio](../../docs/unease_v032/vestigios_preview.mp4) · [Detalhes e validação](../../docs/unease_v032/README.md) · [Instruções completas](../../tools/project_archive_readme.md).

O ZIP é o projeto para o editor; não é um executável de Windows. Caches `.godot`, saves e Git ficam fora do pacote. `PROJETO_MANIFESTO.json` lista hashes dos arquivos; o `.sha256` ao lado verifica o ZIP. [Verificação da distribuição](release_verification.json).
