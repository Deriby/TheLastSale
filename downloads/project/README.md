# Projeto Godot — 0.30.0

**[Baixar TheLastSale_Godot_0.30.0.zip](https://github.com/Deriby/TheLastSale/raw/refs/heads/main/downloads/project/TheLastSale_Godot_0.30.0.zip)**

Extraia em uma pasta nova, importe `project.godot` no **Godot 4.4.1**, aguarde a importação e pressione **F5**. O pacote contém código, modelos animados, cenário, sons, texturas, vídeo e ferramentas. Blender não é necessário para jogar.

A 0.30.0 acrescenta sustos no estoque, uma brincadeira de Bryan na vitrine e uma travessia física no retorno do gerador. Os eventos retomam pelo save; a câmera permanece livre, com terceira pessoa pela rodinha. Modelos, animações, tarefas, energia e campanha foram preservados. [Prévia com som e validação](../../docs/scares_v030/README.md). [Instruções completas](../../tools/project_archive_readme.md).

O ZIP é o projeto para o editor; não é um executável de Windows. Caches `.godot`, saves e Git ficam fora do pacote. `PROJETO_MANIFESTO.json` lista hashes dos arquivos; o `.sha256` ao lado verifica o ZIP. [Verificação da distribuição](release_verification.json).
