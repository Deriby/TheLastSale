# Projeto Godot — 0.11.0

**[Baixar TheLastSale_Godot_0.11.0.zip](https://github.com/Deriby/TheLastSale/raw/refs/heads/main/downloads/project/TheLastSale_Godot_0.11.0.zip)**

Extraia em uma pasta nova, importe `project.godot` no **Godot 4.4.1**, aguarde a importação dos recursos e pressione **F5**.

O ZIP contém modelos animados, cenário, sons, texturas, scripts, testes e ferramentas. O [relatório de otimização](../../docs/optimization_v011/README.md) descreve as reduções de dados e a meta de 30 FPS. A galeria do elenco e a prévia animada estão em [docs/cast_v010](../../docs/cast_v010/README.md). Os originais FBX ficam no pacote de origem fornecido pelo autor; as derivações necessárias ao Godot já estão incluídas.

[Ver SHA-256](TheLastSale_Godot_0.11.0.sha256). O próprio ZIP inclui `PROJETO_MANIFESTO.json`, com os hashes dos arquivos. Para gerar novamente: `python3 tools/package_project.py`.
