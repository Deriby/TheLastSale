# Projeto Godot — 0.34.0

**[Baixar TheLastSale_Godot_0.34.0.zip](https://github.com/Deriby/TheLastSale/raw/refs/heads/main/downloads/project/TheLastSale_Godot_0.34.0.zip)**

Extraia em uma pasta nova, importe `project.godot` no **Godot 4.4.1**, aguarde a importação e pressione **F5**. O pacote contém código, modelos animados, cenário, sons, texturas, vídeo e ferramentas. Blender não é necessário para jogar.

A 0.34.0 refaz as interfaces do computador e das câmeras com uma área de trabalho inspirada no XP: janelas animadas, barra de tarefas, Iniciar, canais laterais, player com pausa e documentos. Campanha, provas, energia, modelos, animações, saves e rodinha ficam preservados. [Prévia real](../../docs/desktop_v034/computador_preview.mp4) · [Galeria e validação](../../docs/desktop_v034/README.md) · [Instruções completas](../../tools/project_archive_readme.md).

O ZIP é o projeto para o editor; não é um executável de Windows. Caches `.godot`, saves e Git ficam fora do pacote. `PROJETO_MANIFESTO.json` lista hashes dos arquivos; o `.sha256` ao lado verifica o ZIP. [Verificação da distribuição](release_verification.json).
