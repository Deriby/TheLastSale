# Projeto Godot — 0.28.0

**[Baixar TheLastSale_Godot_0.28.0.zip](https://github.com/Deriby/TheLastSale/raw/refs/heads/main/downloads/project/TheLastSale_Godot_0.28.0.zip)**

Extraia em uma pasta nova, importe `project.godot` no **Godot 4.4.1**, aguarde a importação e pressione **F5**. O pacote contém código, modelos animados, cenário, sons, texturas, vídeo e ferramentas. Blender não é necessário para jogar.

A 0.28.0 reúne primeira pessoa com terceira pessoa pela rodinha, caderno em J, HUD discreto, luz de comércio, som posicional e tensão gradual durante a rotina. Os acontecimentos retomam pelo save. Modelos, texturas, animações, mecânicas, energia, intro e menu foram preservados. [Prévia com som e validação](../../docs/everyday_v028/README.md). [Instruções completas](../../tools/project_archive_readme.md).

O ZIP é o projeto para o editor; não é um executável de Windows. Caches `.godot`, saves e Git ficam fora do pacote. `PROJETO_MANIFESTO.json` lista hashes dos arquivos; o `.sha256` ao lado verifica o ZIP. [Verificação da distribuição](release_verification.json).
