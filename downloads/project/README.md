# Projeto Godot — 0.35.0

**[Baixar TheLastSale_Godot_0.35.0.zip](https://github.com/Deriby/TheLastSale/raw/refs/heads/main/downloads/project/TheLastSale_Godot_0.35.0.zip)**

Extraia em uma pasta nova, importe `project.godot` no **Godot 4.4.1**, aguarde a importação e pressione **F5**. O pacote contém código, modelos animados, cenário, sons, texturas, vídeo e ferramentas. Blender não é necessário para jogar.

A 0.35.0 acrescenta orientação pelo cenário na sexta: etiquetas fixas, referências na conversa com Felps e uma lista no balcão consultável com E. O caderno J mantém os detalhes; o HUD discreto reduz as indicações de reposição e respeita a preferência salva. Pedidos dos clientes e HUD completo conservam a ajuda visual. Campanha, computador, provas, energia, modelos, animações, saves e rodinha ficam preservados. [Prévia real](../../docs/guidance_v035/orientacao_preview.mp4) · [Galeria e validação](../../docs/guidance_v035/README.md) · [Instruções completas](../../tools/project_archive_readme.md).

O ZIP é o projeto para o editor; não é um executável de Windows. Caches `.godot`, saves e Git ficam fora do pacote. `PROJETO_MANIFESTO.json` lista hashes dos arquivos; o `.sha256` ao lado verifica o ZIP. [Verificação da distribuição](release_verification.json).
