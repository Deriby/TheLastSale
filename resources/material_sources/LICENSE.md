# Surface source textures — Poly Haven / CC0 1.0

These four texture sets are CC0 assets from Poly Haven. The shipped surface maps adapt color, scale, normal strength and roughness for this game. The original JPG inputs are included for offline regeneration. No account, network connection or Blender installation is needed to play.
